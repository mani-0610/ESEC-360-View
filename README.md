# ESEC 360 View

## 🌐 Virtual Campus Tour

**ESEC 360 View** is a web-based virtual campus tour developed for **Erode Sengunthar Engineering College**. It allows users to explore different locations of the campus through 360° images and simple navigation controls.

## ✨ Features

* 🏫 Virtual tour of the college campus
* 🌐 360° view of campus locations
* 🧭 Easy navigation between locations
* 🖼️ Interactive campus images
* 💻 Simple and user-friendly web interface

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript
* 360° Image Technology

## 📷 Project Development

Campus locations were captured using a **360° GoPro camera**. The captured images were converted into 360° interactive images using **Panoee** and integrated into the web application with navigation buttons and icons.
